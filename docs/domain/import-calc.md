# 직구 계산기

## 용어
| 용어 | 뜻 |
| --- | --- |
| 물건 값 | 사용자가 입력하는 외화 금액 (통화 선택) |
| 원화 환산 | 물건 값 × 기준일 환율 |
| 면세 한도 · 관부가세 | 해외 직구 시 세금 기준 (출처 · 값 확인 필요) |

## 불변식 (항상 참이어야 하는 것)
| ID | 규칙 | 검사 |
| --- | --- | --- |
| IMP-01 | 계산은 브라우저 안에서만 — 입력값을 어디에도 보내거나 저장하지 않는다 | |
| IMP-02 | 사용한 환율의 기준일 · 출처를 결과 옆에 표시한다 | |
| IMP-03 | 세금 기준값(면세 한도 · 세율)은 코드에 흩지 않고 한 파일에 출처 · 기준일과 함께 둔다 | |
| IMP-04 | 결과는 "예상 금액"으로 표시하고, 실제 세액은 관세청 기준이라는 안내를 둔다 | |
| IMP-05 | 음수 · 숫자 아닌 입력은 계산하지 않고 이유를 보여 준다 | |

## 확인 필요
- 면세 한도 · 관세율 · 부가세율의 공식 출처와 값 (지어내지 않음)
- 배송비 · 카드 해외결제 수수료를 넣을지
