# 지금 살 때인가 신호

## 용어
| 용어 | 뜻 |
| --- | --- |
| 신호 | 오늘 환율이 최근 기간 안에서 싼 편인지 비싼 편인지의 **위치** |
| 비교 기간 | 신호를 계산하는 과거 구간 (예: 90일) (가정) |

## 불변식 (항상 참이어야 하는 것)
| ID | 규칙 | 검사 |
| --- | --- | --- |
| SIG-01 | 신호는 과거 값 대비 위치일 뿐 — "오른다 · 내린다" 같은 예측 문구를 쓰지 않는다 | |
| SIG-02 | 신호 옆에 계산 방법(비교 기간 · 기준)을 항상 표시한다 | |
| SIG-03 | 비교 기간 데이터가 모자라면 신호를 내지 않는다 (가정: 기간의 80% 미만) | |
| SIG-04 | "투자 · 금융 조언 아님" 안내를 표시한다 | |

## 확인 필요
- 계산 방식: 백분위 · 평균 대비 % · 이동평균 중 무엇으로 할지
- 비교 기간 길이
