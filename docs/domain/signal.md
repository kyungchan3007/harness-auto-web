# 지금 살 때인가 신호

## 용어
| 용어 | 뜻 |
| --- | --- |
| 신호 | 오늘 환율이 최근 기간 안에서 싼 편인지 비싼 편인지의 **위치** |
| 비교 기간 | 최근 90일 (달력 기준 · 오늘 포함) (확인됨) |
| 백분위 | 비교 기간 중 오늘보다 **낮았던** 날의 비율 (0 ~ 1) · 1 외화당 원(`baseRate / unit`)으로 비교 |

## 불변식 (항상 참이어야 하는 것)
| ID | 규칙 | 검사 |
| --- | --- | --- |
| SIG-01 | 신호는 과거 값 대비 위치일 뿐 — "오른다 · 내린다" 같은 예측 문구를 쓰지 않는다 | API `method` 문구 "예측 아님" (`signal.test.ts`) · 화면 문구는 화면 작업에서 |
| SIG-02 | 신호 옆에 계산 방법(비교 기간 · 기준)을 항상 표시한다 | API 가 `method` · `rule` · `window` 를 항상 돌려줌 (`signal.test.ts` "계산 방법은 항상 같이") |
| SIG-03 | 비교 기간 데이터가 모자라면 신호를 내지 않는다 (기간 평일의 80% 미만) | `signal.test.ts` "영업일 80% 미만이면 신호 없음" |
| SIG-04 | "투자 · 금융 조언 아님" 안내를 표시한다 | |
| SIG-05 | 30% 이하 = 싼 편 · 70% 이상 = 비싼 편 · 나머지 보통 (확인됨: "전부 추천대로") | `signal.test.ts` "경계" |

## 계산 위치
