# 환율 (오늘 환율 + 추이)

## 용어
| 용어 | 뜻 |
| --- | --- |
| 기준일 | 데이터가 가리키는 영업일 (수집한 날과 다를 수 있음) |
| 매매기준율 | 은행이 고시하는 기준 환율 (가정 — 수출입은행 API 항목명 확인 필요) |
| 추이 | 기준일 이전 30일 · 1년 값의 흐름 |

## 불변식 (항상 참이어야 하는 것)
| ID | 규칙 | 검사 |
| --- | --- | --- |
| FX-01 | 모든 환율 값은 출처 API와 기준일을 함께 표시한다 | |
| FX-02 | 받지 못한 날(주말 · 공휴일 · 오류)의 값은 만들지 않는다 — 비워 두고 "자료 없음"으로 표시 | |
| FX-03 | 통화 목록은 API 응답에 있는 것 전부 — 코드에 고정하지 않는다 | |
| FX-04 | 100 단위로 고시되는 통화(예: 엔)는 단위를 화면에 표시한다 (가정 — API 형식 확인 필요) | |

- 검사 칸이 비어 있는 규칙 = 아직 문서로만 있는 규칙. 위반이 한 번 나오면 테스트로 옮긴다

## 확인 필요
- 수출입은행 환율 API · 한국은행 ECOS 중 무엇을 주 출처로 쓸지 · 과거 1년치 소급 수집 가능 여부
- API 키 발급은 사용자가 직접
