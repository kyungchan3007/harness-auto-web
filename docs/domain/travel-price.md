# 여행지 물가 비교

## 용어
| 용어 | 뜻 |
| --- | --- |
| 물가 수준 | 한국 대비 여행지의 상대 물가 (지표 · 출처 미정) |
| 체감 물가 | 물가 수준 × 오늘 환율을 합친 값 (가정) |

## 불변식 (항상 참이어야 하는 것)
| ID | 규칙 | 검사 |
| --- | --- | --- |
| TRV-01 | 물가 지표마다 출처 · 기준 연도를 표시한다 (환율보다 갱신이 느림) | |
| TRV-02 | 출처가 없는 나라는 목록에 넣지 않는다 — 추정치로 채우지 않는다 | |
| TRV-03 | 환율 기준일과 물가 기준 연도가 다르면 둘 다 보여 준다 | |

## 확인 필요
- 데이터 출처 (예: 국가별 물가 수준 지수를 주는 공개 API) — **미정, 조사 필요**
- 비교 단위: 나라 · 도시 · 품목 중 무엇으로 할지
