- 애니메이션 원칙: 섹션은 아래에서 살짝 떠오름 · 숫자는 0 → 실제 값 (끝값은 항상 정확) · 스크롤 장면은 화면에 고정하고 진행 · 작은 움직임(탭 밑줄 · 버튼 · 캐릭터 흔들림)
- "움직임 줄이기"면 멈추고 결과만 · 휴대폰은 3D 단순화 · 숫자와 신호는 애니메이션 없이도 항상 글자로
