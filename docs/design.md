## 페이지 패턴 (참고 페이지에서 가져옴)
| 패턴 | 참고 페이지 | 우리 사이트 |
| --- | --- | --- |
| 첫 화면 | 거대한 글자 + 빛 + 제품 · 한 줄 문장 | 거대한 환율 숫자(오로라) + 🌏 지구본 · "오늘, 달러는 싼 편입니다." |
| 둘러보기 | 왼쪽 `+ 크기` 버튼 목록 → 가운데 제품 화면이 바뀜 | 왼쪽 `+ 달러` `+ 엔` `+ 유로` → 가운데 🪙 동전이 바뀜 |
| 요약 카드 | 검정 카드 격자 · 아이콘 하나 + 짧은 문장 · 숫자만 색 | 오늘 요약: 통화별 신호 · 직구 예상액 |
| 이야기 섹션 | 작은 소제목 → 큰 제목 두 줄 → 회색 본문 | 섹션마다 같은 틀 |
| 탭 · 넘기기 | 앱 분야 탭 · 좌우 화살표 | 여행지 탭 · 직구 상품 넘기기 |
| 아이콘 목록 | 선 아이콘 + 굵은 이름 + 회색 설명 | "만드는 중"의 하네스 기능 설명 |

## three.js
| 오브젝트 | 어디에 | 하는 일 |
| --- | --- | --- |
| 🌏 지구본 | 홈 첫 화면 | 한국 → 여행지 호 · 호 색 = 신호 · 스크롤하면 다음 나라로 회전 |
| 🪙 동전 | 통화 둘러보기 · 통화 상세 | 천천히 회전 · 내리면 반짝 · 오르면 살짝 가라앉음 |
| 📈 1년 리본 | 추이 | 1년 환율을 3D 리본으로 · 스크롤로 날짜를 훑음 |
| 🧱 블록 탑 | 만드는 중 | 머지된 PR 하나 = 블록 하나 · 막힌 작업은 빨간 블록 |
| 🧳 · 🐷 캐릭터 | 카드 구석 · 계산 결과 옆 (작게) | 신호에 따라 표정: 쌀 때 웃음 · 비쌀 때 시무룩 · 가벼운 흔들림만 |
