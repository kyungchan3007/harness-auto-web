## 문제
- 홈 "모든 통화" 칸은 오늘 값 · 신호(90일 중 위치)만 — "이번 달 얼마나 싸졌나" 는 통화 상세에 들어가 기간 단추를 눌러야 앎
- 통화 22개의 1년치를 홈 빌드에서 따로 받으면 요청 22개 (D1 읽기 · 빌드 시간)
