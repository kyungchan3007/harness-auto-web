## 무엇을 · 왜
- 사용자와 합의한 디자인 방향을 `docs/design.md` 한 곳에 고정 — 디자인 시스템(`packages/ui`) · 화면 작업이 따를 원본
- **문서만.** 토큰 · 컴포넌트 코드는 디자인 시스템 작업에서

## 애매한 곳
- 참고: Apple MacBook Pro 페이지 느낌 · 로고 · 이미지 · 문구 · 글꼴은 쓰지 않음 (확인됨: "애플 … 이런 느낌의 페이지 처럼")
- 배경: 거의 어둡게 + 밝은 섹션 2~3곳 (확인됨: "거의 어둡게") — 처음 답 "섹션마다 번갈아"에서 바뀜
- 포인트 색: 오로라 그라데이션 청록 → 보라 → 핑크 (확인됨: "오로라 좋다") · 골드 제외 (확인됨: "골드 색갈 너무 구려 안돼")
- three.js: 지구본 · 동전 · 1년 리본 · 캐릭터 · 블록 탑 다섯 가지 모두 (확인됨: "1번 부터 5번까지 전부다")
- 캐릭터: 여행 가방 · 돼지 저금통 · 작은 표시용 · 3D · 신호에 따라 표정 (확인됨: "캐릭터는 그냥 표시 용도" · "3D에 표정 바뀜") · 영상 없음 (확인됨: "영상은 필요없고")
- 라이브러리: 헤드리스 Base UI + Tailwind v4 · three + @react-three/fiber + drei · motion (확인됨: 추천안에 "오케이 시작")
- 신호 색 파랑 = 쌈 · 빨강 = 비쌈 (가정 — 한국 금융 앱 관례)
- 글꼴 Pretendard (가정)
- 색 값(hex)은 후보 — 대비는 토큰 만들 때 측정 (가정)
