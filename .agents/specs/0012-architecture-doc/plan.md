# 계획

## 무엇을 · 왜
- `docs/architecture.md` 를 합의한 구조(Turborepo · VSA · Next.js + Hono on Cloudflare)로 다시 씀 — 이후 모노레포 전환 · API · 디자인 시스템 작업이 따를 기준
- **문서만.** 코드 · 폴더는 바꾸지 않음 (모노레포 전환은 별도 이슈)
- docs/domain 의 "담당 경로"를 새 구조 경로로 맞춤

## 애매한 곳
- 저장소: 모노레포 `apps/web` · `apps/api` · `packages/*` (확인됨: "1번으로 가야지")
- 프론트: Turborepo · VSA (확인됨: "프론트는 터보레포 형식으로 가면될거 같고 그리고 음 VSA 형식으로")
- 백엔드: Hono on Cloudflare Workers (확인됨: "백엔드도 클라우드플레이어로" · Hono 제안에 "시작해")
- 백엔드 내부: 정석 문서 기준 수정안 — 컨트롤러 없이 핸들러 직접 · `app.route()` 로 기능 묶기 · 슬라이스 안은 가볍게 (확인됨: 수정안에 "시작해")
- 디자인 시스템: `packages/ui` 자리만 · 내용(색 · 글꼴 · 톤)은 디자인 논의 때 (확인됨: 디자인은 따로 이야기)
- 데이터 수집 위치(Worker Cron → D1 인지, 저장소 JSON 인지): **미정 — 오픈 데이터 논의 때** (확인됨: "오픈소스 데이터 가져오는거도 이야기해야하고")
- 로그인 방식 · 알림 수단: 미정 (제안: 이메일 매직 링크 · 이메일 알림) (가정)
- 패키지 매니저: npm workspaces 유지 (지금 npm · lock 파일 있음) · 패키지 이름 접두사 `@hav/` (가정)
- 작업 번호 0012: 이슈 #12 와 맞추려고 `spec:new` 대신 템플릿을 직접 복사 (`spec:new` 는 0003 을 줌)
