# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- docs/design.md 의 🧱 블록 탑은 "막힌 작업은 빨간 블록" 인데, 작업 0071 에서 자료가 없어 뺐다
- 실시간 기록(activity_events)은 최근 500줄만 남기고 지워서, 지난 작업이 막혔는지 알 수 없다

## 목표
- 기록이 들어올 때 작업별로 "하네스가 막음" · "게이트 실패" 횟수를 따로 쌓아 지워지지 않게 한다
- `GET /tasks` 가 작업별 막힘 수를 같이 준다
- 블록 탑에서 막힘이 있었던 작업의 블록을 빨갛게 · 몇 개인지 글자로도 (색만으로 전하지 않음)

## 비목표
- 기록 훅(.agents/scripts/activity.mjs) 은 바꾸지 않음 — 이미 kind · ok · task 를 보냄
- 500줄보다 먼저 지워진 기록은 되살릴 수 없음 → 지금 남은 기록으로만 처음 값을 채우고, 그 날짜를 화면에 적음

## 애매한 곳
- "막힘" = kind `blocked` (하네스가 막음) 또는 kind `gate` 이면서 ok = false (게이트 실패) (가정 · /log 의 "오늘 하네스가 막은 것" 과 같은 뜻에 게이트 실패를 더함)
- 작업 번호가 없는 기록은 셀 수 없음 → 뺌
- 한 작업에 PR 이 여럿이면 그 작업의 PR 블록 모두 빨강 (가정 · 막힘은 PR 이 아니라 작업에 붙어서)
