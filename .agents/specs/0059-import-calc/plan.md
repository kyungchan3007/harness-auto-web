# 계획

## 무엇을 · 왜
- 직구 계산기 `/calc` (시안 2 그대로 · 밝은 배경)
  - 입력: 통화(API 가 준 전부) · 물건 값 · 보내는 곳 · 국제 배송비 · 관세율 %
  - 결과: 원화 · 면세 한도 막대 · 남은 한도 · 넘으면 관세 · 부가세 · 합계 예상 · 🐷 돼지 표정 (한도 안 웃음 · 가까우면 걱정 · 넘으면 시무룩)
  - `/calc?currency=JPY` 로 열면 그 통화 (통화 둘러보기에 "이 통화로 직구 계산하기 →")
- 세금 기준값은 한 파일에 출처 · 확인한 날과 함께 (IMP-03) — `features/import-calc/rules.ts`
  - 면세 한도: 목록통관 미국 200달러 · 그 밖 150달러 · 일반통관(수입신고) 150달러 (관세청 예상세액 조회 페이지, 2026-10-29)
  - 한도 넘으면 물건 값 + 국제 운임에 과세 · 부가세 = (과세가격 + 관세) × 10%
  - 관세율은 품목마다 달라 지어내지 않음 → 사용자가 넣음 · 비우면 면세 여부 · 남은 한도만
- 계산은 브라우저 안에서만 · 어디에도 보내지 않음 (IMP-01) · 순수 함수 + 테스트 (IMP-02 ~ 05)
- 🐷 돼지 저금통 → `@hav/ui/three/piggy` (표정 이름만 받음)
- 상단 메뉴에 "직구 계산"

## 애매한 곳
- 시안 그대로 (확인됨: "이대로 시작")
- 한도 비교용 달러 환산은 우리 환율(수출입은행)로 교차 계산 — 실제는 관세청 과세환율 (가정 · 화면에 안내)
- 개별소비세 · 교육세 · 주세 등은 빼고 관세 · 부가세만 (가정 · 화면에 안내)
- 같은 날 여러 건 합산 과세 · 목록통관 제외 품목(건강기능식품 등)은 안내 글로만 (가정)
- "한도에 가까움" = 한도의 80% 이상 (가정 · 돼지 표정만)
