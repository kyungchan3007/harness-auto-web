## 문제
- 게이트 Full 루프는 `test:e2e` 가 있으면 돌리는데, 저장소에 e2e 가 하나도 없어 **조용히 건너뛰고 있었음**
- 오늘 만든 화면 기능(계산기 · 기간 · 예산 · 즐겨찾기 · 일지 · 정렬)은 손으로 쓴 임시 스크립트(.tmp)로만 확인 — 다음에 깨져도 모름
- 작업 0092 의 깨진 링크(href 가 오류 글자)도 화면 캡처로는 안 보였음
