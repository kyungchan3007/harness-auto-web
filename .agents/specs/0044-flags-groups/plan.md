- 국기 · 전체 통화 · 그룹 (확인됨: 원문)
- 그룹 기준: 지역 (가정 — 사용자에게 알림)
- 국기 방식: SVG (이모지 국기는 Windows 에서 글자로 보임) (가정)
- 유로 = EU 국기 · 위안(CNH) = 중국 · 처음 열린 탭 = 아시아 (가정)
- API 가 표에 없는 통화를 새로 주면 "기타" 탭에 코드 그대로 (FX-03: 코드에 통화 목록을 고정하지 않음)
