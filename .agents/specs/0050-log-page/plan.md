## 애매한 곳
- 만드는 중 탭 · 가운데 패널 · 스크롤 애니메이션 (확인됨: 원문)
- 두 곳 이상 쓰면 디자인 시스템 (확인됨: 원문) — 단, Tripfx 메뉴 링크 · 로고처럼 **이 사이트 설정**은 `apps/web/src/shared/site-nav.tsx` (디자인 시스템은 사이트 이름을 모르게) (가정)
- "작업 중" = 마지막 기록이 10분 안 · 그 밖은 "쉬는 중 · 마지막 작업 ○ 전" (가정)
- 기록은 최근 50줄만 화면에 · 새 줄은 오로라로 잠깐 반짝 (가정)
- GitHub API 는 인증 없이 (시간당 60번 · 빌드 때만 부름) · 실패하면 "불러오지 못함" (가정)
- 숫자는 실측만: 머지된 작업 수 · 오늘 기록 수 · 오늘 막힌 수 (가정)
- 보호 파일(잠금 파일) 승인: 에이전트 (확인됨: "라벨도 네가 붙여")

## 허점
- 휴대폰에서 메뉴가 숨어 있어 "만드는 중"에 갈 수 없었음 (원래 있던 문제) → 메뉴는 늘 보이고 버튼은 넓은 화면에서만
- motion 은 color-mix · height auto 를 매끄럽게 못 바꿈 → 반짝임은 덮개 투명도, 상태 줄은 투명도만
- 오늘 숫자는 받은 최근 50줄 안에서만 셈 (화면에 적어 둠)
- 첫 미리보기 빌드에서 GitHub 이 10초 안에 안 와서 지난 작업 0개 (화면엔 "불러오지 못함 (시간 초과)") → User-Agent · 20초 · 한 번 더
- 지난 작업 · 작업 이름은 빌드 때 받음 → 새 이슈 이름은 다음 빌드부터 (그 전엔 "작업 NNNN")
