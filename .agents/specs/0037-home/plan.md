## 애매한 곳
- 화면 구성 · 애니메이션 (확인됨: 에이전트 제안 3 · 4번에 "오케이 시작해")
- 첫 화면 주인공 통화: 미국 달러 (가정 — 제안 문장 "오늘, 달러는 싼 편입니다.")
- 카드에 보일 통화: 엔 · 유로 · 위안 · 파운드 · 태국 바트 · 베트남 동 중 응답에 있는 것 (가정 — 여행 · 직구가 많은 곳)
- 통화 한국어 이름은 화면 쪽 작은 표 (가정 — API 는 코드만 줌)
- 신호 문장: 싼 편 "오늘, 달러는 싼 편입니다." · 보통 "평소 수준입니다." · 비싼 편 "비싼 편입니다." · 신호 없음 "판단할 자료가 모자랍니다." — 예측 문구 없음 (SIG-01)
- 백분위 문장: "최근 90일 중 N%의 날보다 낮음" (cheap) / "높음" (expensive) / 보통은 "가운데쯤" (가정)
- 사이트는 빌드 때 데이터 — 매일 다시 빌드하는 건 다음 작업 (배포 훅)
