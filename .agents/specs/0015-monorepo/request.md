## "시작"이 가리킨 순서 (에이전트 제안 원문)
1. **디자인 문서** (`docs/design.md`) → PR → 머지
2. **모노레포 전환**: 지금 앱을 `apps/web`으로 옮기고 Turborepo를 세팅 → PR → 머지
3. **디자인 시스템** (`packages/ui`): 토큰 · 기본 컴포넌트 · 예시 화면 → PR → 머지
