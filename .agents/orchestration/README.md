# 🎼 오케스트레이션 (선택 · 기본 꺼짐)

> **여러 에이전트가 하나의 목표를 위해 일할 때, 누가 · 무엇을 · 어떤 순서로 · 무엇을 넘겨받아 · 어떻게 합칠지 정하는 것**

- 에이전트가 하나면 필요 없다. 하네스(게이트)만으로 충분하다
- MCP는 연결 수단일 뿐 오케스트레이션이 아니다 (MCP · CLI · 서브에이전트 무엇으로 연결해도 됨)
- 이 폴더는 **뼈대**다. 칸은 비어 있고, 켤 때 프로젝트에 맞게 채운다

## 언제 켜나
| 상황 | 켤까 |
| --- | --- |
| 작은 작업 · 에이전트 하나 | ❌ 큰 모델 하나 + 게이트가 더 싸고 정확 |
| 한 세션 컨텍스트에 안 들어가는 큰 작업 | ✅ |
| 여러 에이전트가 동시에 다른 작업 | ✅ 상태 공유 · 충돌 방지 필요 |
| 만든 에이전트가 자기 작업을 채점 | ✅ 검증을 분리 |

## 켜는 법
1. 패턴 하나 고르기 → 해당 `patterns/*.md` 채우기
2. 그 패턴에 나오는 역할만 `roles/*.md` 채우기 (안 쓰는 역할은 지워도 됨)
3. `AGENTS.md` "어디에 무엇이" 표에 이 폴더 한 줄 추가
